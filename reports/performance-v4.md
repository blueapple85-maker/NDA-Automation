# NDA Studio 속도 최적화 검증

검증일: 2026-09-22. 실제 NDA와 외부 AI API를 사용하지 않은 로컬 검증입니다.

## 변경 내용

- 동일 검토 건의 동일 회사·조건·모델·추론 강도·프롬프트에 대한 완료 결과와 V1 재사용. 실패 결과는 저장하지 않으며 조건 변경 시 새로 검토합니다.
- 같은 권고 선택의 V2 재사용. 추가 채택이 없으면 V1 내용으로 최종 파일을 제공합니다.
- 닫힌 입력 해석·체크리스트·수정 내역 패널은 처음 열 때 구성합니다. 기타 조항 요약과 채택 선택지는 즉시 표시합니다.
- 공개 화면 파일에 gzip/ETag 적용. API와 계약 파일은 no-store 유지.
- 화면에서 사용하지 않는 1~16번 내부 목록의 중복 설명을 생성하지 않도록 지침과 스키마 설명을 조정했습니다. 모든 문단의 근거, 체크리스트, 수정안과 기타 조항 요약은 검증합니다.

모델은 `gpt-5.4-mini`, 초기 분석 low / 법률검토 medium으로 유지했습니다.

## 전송량

HTTP 응답의 본문 크기 비교입니다. 이후 방문 시 변경되지 않은 파일은 ETag 재검증으로 304 응답합니다.

| 파일 | 기존 전송량 | 최적화 후 gzip 전송량 |
| --- | ---: | ---: |
| HTML | 19,340 bytes | 6,546 bytes |
| CSS | 37,078 bytes | 8,557 bytes |
| JavaScript | 22,567 bytes | 8,152 bytes |
| 합계 | 78,985 bytes | 23,255 bytes |

본문 전송량 약 **70.6% 감소**. 첫 AI 검토의 처리 시간이 같은 비율로 줄어든다는 의미는 아닙니다.

## 화면 표시

격리된 Headless Chrome, 1440×1080. 수정사항 60개, 수정 전후 각각 약 2,000자의 합성 데이터를 사용했습니다. 변경 전후를 번갈아 각각 5회 측정했습니다. 실제 문서의 생성·다운로드 속도나 외부 AI 추론 시간은 이 수치에 포함되지 않습니다.

| 측정 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| 검토 버튼 클릭부터 결과 화면 다음 프레임까지 중앙값 | 66.9 ms | 60.7 ms |
| 처음 구성한 결과 화면 요소 | 852 | 117 |
| 닫힌 수정 내역 패널 내부 요소 | 600 | 0 |

패널을 열면 수정사항 60개와 전체 수정 전후 텍스트가 정상 표시됨을 확인했습니다. 시간 차이는 장치·문서·응답 상태에 따라 달라집니다.

## 자동 검증

61개 테스트 통과: 동일 요청의 추가 AI 호출 없음, 회사·조건·모델·추론 변경 시 재호출, 다른 업로드 건과 격리, 실패 후 실제 재시도, V1/V2 파일 내용, 지연 표시와 재열기, 최신 수정사항 반영, gzip/ETag와 소스 변경 감지, 비공개 파일 no-store, 기존 원문 인용 및 출력 한도 오류 처리.

실행: `node --test tests/config.test.cjs tests/evidence.test.cjs tests/studio.test.cjs tests/api.test.cjs tests/ui.test.cjs`.

서버 재시작 후 격리된 Chrome에서도 1440×1080 / 390×844의 4단계 데모 흐름을 통과했습니다. 회사 선택, 전체 채택·선택 해제, 최종본 재생성, 실제 DOCX 다운로드, 검토 삭제를 확인했으며 가로 넘침과 브라우저 오류가 없었습니다.

측정 원본은 Git 제외 경로 `.runtime/performance-results.json`입니다. 실제 NDA를 통한 AI 검토 시간과 프롬프트 변경의 법률 검토 품질은 별도로 측정하지 않았습니다.
