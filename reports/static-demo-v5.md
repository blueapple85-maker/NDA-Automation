# Vercel 정적 데모 전환 검증

검증일: 2026-09-22

Vercel 기본 배포는 `npm run build` → `dist` 정적 파일입니다. 가상의 예시 NDA와 사용자 입력을 브라우저에서 처리하며 서버·API 키·외부 저장소를 요구하지 않습니다. 기존 로컬 AI 앱은 `npm start`로 계속 실행합니다.

## 확인 결과

- Node.js 테스트 74개 통과: 기존 API·AI 검증·로그·화면 회귀 검사와 정적 데모 5개 검사 포함.
- Chrome에서 1440×1080 및 390×844의 네 단계 화면 확인. 가로 넘침과 브라우저 오류 없음.
- Vercel 설정과 동일한 CSP를 적용한 정적 HTTP 페이지, `file://`로 직접 연 HTML 모두 V2 다운로드 성공.
- 화면 로드 후 네트워크를 끊어도 조건 입력 → V1 생성 → 권고 채택 → V2 다운로드 성공. API 호출 0건.
- 체험용 DOCX 다운로드와 재업로드 성공. 다른 계약·원문 수정·변경 이력·손상 파일·DOC를 예시 결과로 대체하지 않고 거부.
- 한글·영문 입력의 문자 보존, 회사 변경에 따른 Note 수신인 변경, 조건 변경 시 이전 수정본 무효화, 초기화 시 Blob URL 해제 확인.
- 브라우저 생성 V1/V2를 실제 Microsoft Word의 별도 비표시 인스턴스에서 열어 확인: V1 변경 61개, V2 변경 89개 인식. 각 파일에서 모두 수락한 텍스트는 예상 수정본과, 모두 거절한 텍스트는 예시 원문과 일치.
- 공개 출력은 HTML, CSS, JavaScript와 라이선스 파일뿐. API 키 파일, 환경변수 파일, 서버 AI 모듈, 실제 NDA, 로그는 포함하지 않음.

## 범위

예시 문서 전용 기능 시연입니다. 일반 NDA의 AI 분석·법률 판단·번역·DOC 변환은 제공하지 않습니다. 한국어·영어 조건은 입력 그대로 수정본에 삽입합니다. 이 검증에서는 실제 NDA나 OpenAI API를 사용하지 않았습니다.

원격 Vercel 프로젝트를 재배포한 결과는 포함하지 않습니다. 연결된 저장소에 소스 변경을 반영하고 README의 설정으로 재배포해야 합니다. 이후 `/api/demo` 자체는 정적 사이트에서 404이며, 화면은 이 API를 호출하지 않습니다.
