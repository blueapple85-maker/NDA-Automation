# NDA Studio 프롬프트

- [실제 검토 지시 v3](nda-review-system.md): 서버가 매 검토 요청마다 읽는 현재 파일입니다. 수정 후 다음 검토부터 적용됩니다.
- [웹사이트 제작 프롬프트](nda-website-build.md): 4단계 웹사이트와 문서 처리, 최신 17개 기준을 만드는 지시입니다.
- [이전 검토 지시](nda-review-system.previous.md): 기존 버전 보관용이며 현재 서버가 사용하지 않습니다.

사용 목적과 준거법·분쟁해결·계약기간·존속기간은 한국어 또는 영어로 입력합니다. 대리 회사는 명시적으로 선택하며, 빈 대체 입력은 원문을 유지합니다. 준거법과 분쟁해결 메모는 검토 13번·14번으로 구분합니다. 17번은 문제없는 기타 조항을 포함해 모두 요약하며, 권장 수정은 채택한 경우에만 최종본에 반영합니다.

이전 `nda-review-input-template.md`, 비교 분석 보고서, 프런트엔드 프롬프트 번들은 과거 작업의 참고자료이며 현재 서버의 입력 규약이나 검토 기준을 덮어쓰지 않습니다. 현재 출력 형식은 `server/schemas.cjs`와 일치해야 합니다.

사용과 문제 해결은 [프로젝트 README](../README.md)를 참조하세요.
