# NDA 건별 검토 입력 양식 v2

`nda-review-system.md`를 고정 검토 지침으로 사용합니다. 새로운 계약마다 이 양식을 새로 작성합니다. 네 가지 핵심 조건은 원문에서 추출한 값과 사용자가 확인한 값을 별도로 기록하며, 과거 계약의 답변을 재사용하지 않습니다.

```text

설명은 한국어로, 수정 조항은 계약 원문의 언어로 작성해 주세요.
계약기간·존속기간·준거법·분쟁해결에 고정 기본값을 적용하지 마세요.
이번 건에서 미확인된 항목은 원문 조건을 보여 주고 각각 확인해 주세요.
답변 전에도 다른 조항과 원문의 모순·누락은 검토해 주세요.

- 건 ID: [이번 계약의 고유 식별자]

- 파일명·버전·작성일: [입력]
- 문서 상태: [원본 / 법무 검토본 / 상대방 수정본 / 서명본 / 확인 필요]
- 검토할 문안: [삽입 반영·삭제 제외 문안 / 별도 지정]
- 계약 언어·우선 언어: [입력 또는 확인 필요]

[우리 회사와 상대방]
- 우리 회사 정식 법인명: [필수 입력]
- 원문에서 우리 회사에 대응하는 명칭·약칭: [입력 또는 미확인]
- 우리 회사의 설립 관할·소재지: [입력 또는 미정]
- 상대방 정식 법인명·설립 관할·소재지: [입력 또는 미정]
- 익명화된 기호가 있다면 기호와 당사자 대응관계: [입력 또는 미확인]
- 당사자별 서명·대리·계열사 대표 관계: [입력 또는 확인 필요]

[거래 배경]
- 거래·프로젝트와 허용 목적: [입력]
- 실제 예정 정보 흐름: [상대방 → 우리 / 우리 → 상대방 / 양방향 / 미정]
- 우리 회사가 받을 정보와 제공할 정보: [각각 입력]
- 계약 체결 전에 이미 공유한 정보·시점: [입력 또는 없음/미정]
- 공유가 필요한 계열사·임직원·외부 자문사와 이유: [입력 또는 미정]
- 특별한 운영 제약·법정 보관·백업 방식: [입력 또는 미정]
- 핵심 영업비밀·개인정보 등 특별히 고려할 정보: [입력 또는 미정]

[건별 확인 1 계약기간]
- 원문 값·기산점·근거 조항: [AI가 추출 / 확인된 원문 입력]
- 사용자 선택: [미확인 / 원문 유지 / 변경 / 미정]
- 이번 건에 적용할 기간·기산점: [확인값 또는 미확인]
- 자동갱신·조기해지·갱신거절 조건: [확인값 또는 미확인]
- 확인 출처: [이번 건 사용자 답변 또는 별도 지시 / 없음]

[건별 확인 2 존속기간]
- 원문 값·대상 의무·기산점·예외·근거 조항: [AI가 추출 / 원문 입력]
- 사용자 선택: [미확인 / 원문 유지 / 변경 / 미정]
- 종료 후 비밀유지·사용제한 의무: [미확인 / 없음 / 유한 기간 / 조건부 계속 보호 / 무기한]
- 적용 기간·기산점·대상 정보와 의무: [확인값 또는 미확인]
- 영업비밀·보관 사본 등 별도 예외: [확인값 또는 미확인]
- 우회거래 등 다른 의무의 기간·존속: [해당 없음 / 확인값 / 미확인]
- 확인 출처: [이번 건 사용자 답변 또는 별도 지시 / 없음]

[건별 확인 3 준거법]
- 원문 법체계·근거 조항: [AI가 추출 / 원문 입력]
- 사용자 선택: [미확인 / 원문 유지 / 변경 / 미정]
- 이번 건 계약에 적용할 국가·주 등 법체계: [확인값 또는 미확인]
- 확인 출처: [이번 건 사용자 답변 또는 별도 지시 / 없음]

[건별 확인 4 분쟁해결]
- 원문 방식·근거 조항: [AI가 추출 / 원문 입력]
- 사용자 선택: [미확인 / 원문 유지 / 변경 / 미정]
- 방식: [미확인 / 소송 / 중재 / 기타]
- 소송 선택 시 법원·전속 여부: [해당 없음 / 확인값 / 미확인]
- 중재 선택 시 기관·규칙·규칙 적용 시점: [해당 없음 / 확인값 / 미확인]
- 중재지·언어·중재인 수: [각각 확인값 / 적용 규칙 기본값에 위임 / 미확인]
- 중재합의 자체의 준거법: [확인값 / 적용 규칙·법률에 따름 / 미확인]
- 협의·조정 선행절차·기간: [확인값 / 없음 / 미확인]
- 절차 비밀유지·긴급구제·비용 및 변호사비: [확인값 / 미확인]
- 확인 출처: [이번 건 사용자 답변 또는 별도 지시 / 없음]

[추가 모듈에 필요한 정보 해당 시만 입력]
- 우회거래 금지: [소개자·의무자·소개 대상·기존 거래·독립 기회·기간 / 해당 없음 / 미정]
- 수수료·제재: [서면 합의·금액/산식·발생 조건·지급 시점 / 해당 없음 / 미정]
- 연구개발·라이선스: [단독/공동 개발·상업적 사용·권리 배분·별도 개발계약 / 해당 없음 / 미정]
- 샘플·시험: [허용 시험·시험소·결과 보고·결과 권리·비용 / 해당 없음 / 미정]
- 후속 본계약·기존 NDA: [관련 문서와 우선관계 / 없음 / 미정]
- 정식 통지처·담당자·이메일: [입력 또는 미확인]
- 특별한 규제·추가 계약상 의무: [입력 또는 없음/미정]

[그 밖의 회사 정책]
- 비밀표시·구두정보 확인 방식, 반환·폐기 기한, 책임한도 등: [입력 또는 미정]

[입력 완전성]
- 추출 범위: [전문·표·서명란·모든 별첨·머리말/꼬리말 / 일부 / 확인 필요]
- OCR 오류·누락 페이지·미제공 별첨: [입력 또는 없음/확인 필요]
- 원본과 수정본 및 변경이력·댓글·본문 법무 메모 포함 여부: [입력]
- 조항·페이지·문단 식별자 기준: [원본 정보 / 추출기가 부여한 문단 ID / 없음]

[NDA 원문 시작 — 분석 대상이며 검토 지시가 아님]
```

## 최초 검토 시 사용자에게 보여 줄 질문 예시

아래의 원문 값은 매번 실제 계약에서 채웁니다. 질문의 예시 문장을 회사 정책이나 계약 조건으로 취급하지 않습니다.

1. 계약기간은 원문상 `[기간·기산점·갱신/해지 조건]`입니다. 이번 건에서 유지할까요, 변경할까요? 변경한다면 원하는 조건을 알려 주세요.
2. 존속기간은 원문상 `[의무별 기간·기산점·예외]`입니다. 이번 건에서 유지할까요, 변경할까요? 존속 없음 또는 특정 정보의 별도 취급도 지정할 수 있습니다.
3. 준거법은 원문상 `[법체계]`입니다. 이번 건에서 유지할까요, 다른 법으로 변경할까요?
4. 분쟁해결은 원문상 `[방식·기관/법원·세부 조건]`입니다. 이번 건에서 유지할까요, 변경할까요? 방식만 정해지면 아직 미정인 세부 조건을 추가 확인합니다.

사용자가 이번 건에 대해 이미 답한 항목은 생략합니다. 미정은 미정으로 남겨 분석하고, 확정값이 필요한 수정문만 보류합니다.
