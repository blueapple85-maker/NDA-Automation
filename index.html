검토 서비스 연결

웹 화면과 예시 체험은 로컬 서버에서 실행됩니다. 실제 계약 분석에는 AI API 키가 필요합니다.

  1. NDA-Automation 폴더 바로 위의 key.txt에 API 키를 한 줄로 저장합니다.
  2. 서버가 시작할 때 해당 파일을 우선 읽습니다. 키는 브라우저에 전달하지 않으며 .env에 복사할 필요가 없습니다.
  3. start.cmd를 실행하고 localhost:4173에 접속합니다. 키 변경 후 서버를 다시 실행하세요.

다른 위치의 파일은 .env의 OPENAI_API_KEY_FILE로 지정할 수 있습니다. 기본 키 파일이 없으면 OPENAI_API_KEY 환경변수를 사용합니다.

문서는 이 서버의 메모리에 최대 2시간 보관됩니다. DOC 변환 임시 파일은 변환 직후 삭제합니다. OpenAI API 요청에는 store:false를 사용하며, 제공자의 데이터 처리 정책이 별도로 적용됩니다.
